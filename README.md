# PoC Jest - Carrito de Compras

Prueba de Concepto (PoC) realizada para investigar y evaluar Jest como framework de testing para aplicaciones desarrolladas con JavaScript y Node.js.

## Demo

La demo consiste en un carrito de compras simple que permite:

- Agregar productos.
- Calcular el total.
- Eliminar productos.
- Vaciar el carrito.

También se implementaron pruebas para demostrar:

- Pruebas unitarias.
- Assertions.
- Mocks y spies.
- Pruebas asíncronas.
- Cobertura de código.

## Estructura

- `src/`: contiene la lógica del carrito y los productos.
- `tests/`: contiene las pruebas automatizadas.
- `package.json`: contiene la configuración del proyecto y el script para ejecutar Jest.
